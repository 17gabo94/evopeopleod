# EvoPeople Web Platform Constitution

## Core Principles

### I. Quality-First
All deliverables must meet high standards of functionality, reliability, and user experience before deployment. Code reviews, automated testing, and manual QA are non-negotiable checkpoints. Quality is not a trade-off for speed; broken features are not acceptable shortcuts.

### II. Mobile-Responsive Design
The platform MUST provide an optimal experience across all device sizes and orientations—desktop, tablet, and mobile. Every feature and page must be tested on multiple breakpoints. Performance on mobile networks is critical; responsive design includes adaptive loading and efficient resource use.

### III. SEO & SEM Experience
All content and functionality MUST be optimized for search engine discoverability and paid search campaigns. This includes semantic HTML, structured data markup, fast page load times, mobile optimization, and clear information architecture. Marketing and development teams collaborate to ensure SEO/SEM requirements are integrated from the start, not bolted on later.

## Governance

### Constitution Authority
This constitution supersedes all other development guidelines and project practices. All decisions, features, and processes MUST align with these core principles. When principles conflict with timelines or resource constraints, the principles prevail.

### Amendment Process
Amendments to this constitution require:
1. Clear documentation of the change and rationale
2. Stakeholder approval from both development and business leadership
3. Version bump following semantic versioning rules (MAJOR for principle redefinition, MINOR for additions or clarifications, PATCH for wording refinements)
4. A migration or transition plan if existing work must adapt

### Compliance & Verification
- All PRs/code reviews MUST verify compliance with these principles
- Feature work should include acceptance criteria tied to specific principles
- Regular retrospectives should assess adherence to governance and principle effectiveness
